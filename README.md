# Ayesha Khan — Professional Portfolio

## Run the website
1. Extract this ZIP.
2. Open the `Ayesha_Khan_Portfolio` folder in Visual Studio Code.
3. Open `index.html` in your browser, or install the Live Server extension and choose **Open with Live Server**.

## Files
- `index.html` — all website sections and content
- `style.css` — emerald, gold and ivory theme, responsive layout and animations
- `script.js` — mobile menu, theme toggle, reveal animations, project filters and contact email action
- `assets/ak-logo.svg` — custom AK monogram logo
- `assets/ayesha-khan-cv.pdf` — starter CV PDF

## Notes
- University name is intentionally omitted.
- Canada experience is described as Social Media & Digital Marketer and running digital advertising campaigns.
- Contact form opens the visitor's email application with a pre-filled message; it does not send through a server.
- The avatar and waving goodbye character are CSS/SVG illustrations included in the page.
- Add verified employment dates, specific project links, and any confirmed achievements before publishing.

## Publish
Upload the folder contents to a GitHub repository, then import that repository into Vercel. This is a static HTML/CSS/JS website, so no build command is required.
